📅 Schedule
Calendar-style tasks you set up — daily, weekly, one-time, or every N minutes. These can remind you and/or generate a small file, but never click/buy/delete/move anything or run code — same boundary as Advanced Proactivity, just for things you scheduled yourself. Also try just telling Wizard in chat, e.g. "every day at 8am remind me to stretch."
